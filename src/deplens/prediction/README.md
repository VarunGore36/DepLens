# `prediction` — Status: `in progress` (Phase 4)

`baselines.py` implements the four Phase 4 heuristics over `UpdateCase` (major-version, direct-dependency, API-change, dependency-depth) plus a `code-usage` rule for RQ4 ablation, with `run_baselines` for joint scoring. `cases.py` builds measured cases from the dependency graph, import links, and API usage (`affected_imports`, `affected_apis`, depth, direct flag). Phase 6 (initial, unevaluated): `hybrid.py` weighted-signal model with grid-search F1 fitting, `llm.py` experimental `ApiDiffProvider` seam with an `llm-assisted` rule — both must beat baselines on real data per RQ5 before any claim is made.
